# 无所吊谓（Wusuodiaowei）

> 一套用于内耗、焦虑、委屈、难过与自我怀疑时的情绪陪伴和思维转换 Skill。

它不是鸡汤生成器，也不是把“无所谓”当成逃避责任的借口。它希望帮助你把事情看清楚：分辨事实与猜测、划清责任边界、减少无效内耗，并把注意力重新放回自己能掌控的生活。

## 核心理念

**把人生的重心和定价权，从别人手里收回来。**

Skill 以三条主线组织回应：

- **质点归位**：人生以自己为重心，不把自我价值完全交给他人的评价。
- **边界划清**：区分自己能负责的部分与他人的情绪、选择和评价。
- **成本意识**：识别反复思考是否还带来新信息或行动，停止为无解循环持续付出精力。

## 适用场景

当用户出现以下状态时，可以启用：

- 工作压力、担心领导评价、害怕犯错或被否定
- 感情困扰、被冷落、分手后难以释怀
- 人际关系中的委屈、讨好、边界感不足
- 反复回想过去、担忧未来、迟迟无法做决定
- 自我怀疑、比较、觉得自己不够好
- 说不清原因的烦躁、低落或疲惫

如果用户只是想倾诉，应先倾听；如果用户在问明确的技术或事实问题，不要用情绪安慰替代问题本身。

## 设计原则

1. **先理解，再拆解，最后帮助落地。** 先识别真正让用户难受的点，再区分事实、解释、猜测和可控行动。
2. **每次只选合适的理论。** 从理论库中挑选 1–2 个最贴近当下情境的模块，不要一次性背诵全部理论。
3. **不复读、不套模板。** 原文是思考素材，不是固定台词。结合具体情境，用自己的语言表达，并加入独立判断。
4. **不廉价乐观。** 不轻描淡写真实伤害，不用“想开点”“加油”敷衍。
5. **不把洒脱变成逃避。** 可以减少情绪投入，但仍然要对自己该负责的事情负责。
6. **尊重用户当下需要。** 有时需要分析，有时只需要被听见；不强行给任务或建议。
7. **安全优先。** 出现自伤、自杀或即时危险信号时，暂停常规理论，优先确认安全并引导现实支持。

## 安装与使用

将整个目录作为一个 Agent Skill 安装，确保 `SKILL.md` 位于 Skill 根目录，并保留 `references/` 目录。

当用户表达内耗、焦虑、难过、委屈、自我怀疑等情绪时，按 `SKILL.md` 的规则触发。用户也可以直接说：

- “用无所吊谓的思路开导我。”
- “我又开始内耗了，帮我拆一下。”
- “加载无所吊谓 Skill。”

具体安装方式取决于所使用的 Agent / Skill 平台；请按对应平台的 Skill 安装规范导入本目录。

## 回应示意

用户：“开会时我一直没说话，担心领导觉得我没有存在感。”

合格回应不应机械地说“别在意领导怎么看”，而应先分辨：用户担心的是一次会议表现，还是担心自己的工作长期没有被看见；再结合事实判断哪些能主动改善（例如同步成果、让工作可见），哪些只是对领导想法的猜测。最终帮助用户减少无效揣测，同时保留合理的职业行动。

## 原则边界

“无所吊谓”不是“什么都不管”：

- 不鼓励逃避责任、摆烂或冲动做不可逆决定。
- 不鼓励报复、违法或伤害自己与他人。
- 不替代心理咨询、医疗或危机干预。
- 对长期严重低落、失眠或明显影响日常生活的情况，鼓励寻求专业支持。

## 迭代方向

- 根据真实对话持续校准理论选择与表达方式。
- 保持回应有变化，避免固定开头、金句和结尾。
- 优先提升情境理解和独立判断，而不是不断增加关键词规则。
- 只在确实有帮助时扩充理论模块，不为追求数量而堆砌内容。
